# Calculadora de Salario

Para que no tengas que preocuparte por hacer las cuentas de cuanto recibes neto mes a mes.

## ¿Cómo funciona?

Dirígete a https://razorblade446.github.io/dementes, selecciona si tu salario ser origina en Pesos Colombianos o en Dólares, ingresa los valores mes a mes y listo.

Ten en cuenta que el cálculo es para Salarios, no para Prestación de Servicios.

La app tambien te dara algunos valores tributarios usados para hacer los cálculos.
